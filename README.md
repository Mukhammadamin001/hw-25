# Homework #25 — Музыкальный плеер

Плеер по макету: три категории (**Jazz**, **Classic**, **Blues**), список треков выбранной
категории и нижняя панель управления — play/pause, предыдущий/следующий трек, громкость,
прогресс воспроизведения. Есть тёмная и светлая темы (кнопка в правом верхнем углу).

## Запуск

Проект — обычные HTML/CSS/JS без сборки. Нужен любой локальный сервер:

- **VS Code:** правый клик по `index.html` → **Open with Live Server**;
- **или в терминале:** `npx live-server` в папке проекта.

> Открыть `index.html` двойным кликом не получится: `tracks.json` загружается через
> `fetch`, а браузер запрещает это для страниц `file://`.

Сайт работает и на GitHub Pages без изменений: все пути относительные.

## Структура

```
index.html            разметка: сайдбар, шапка плейлиста, список, нижняя панель
src/
  main.js             состояние, логика плеера, отрисовка списков, события
  style.css           вёрстка по макету, тёмная/светлая тема, адаптив
  icons.js            SVG-иконки
  utils.js            formatTime(), склонение «трек/трека/треков», localStorage
public/
  tracks.json         массив всех треков — список строится из него
  favicon.svg
  music/
    jazz/1.mp3 … 6.mp3
    classic/1.mp3 … 8.mp3
    blues/1.mp3 … 7.mp3
scripts/              генератор музыки (см. ниже)
```

## Данные

`public/tracks.json` — массив всех треков, `id` сквозной по всем категориям:

```json
{
  "id": 3,
  "title": "Smoke & Saxophone",
  "artist": "The Quiet Trio",
  "category": "jazz",
  "file": "public/music/jazz/3.mp3",
  "duration": 135.66
}
```

`duration` необязателен: он нужен только чтобы показать длительность в списке ещё до
загрузки файла. Точное значение плеер берёт из события `loadedmetadata`.

## Как устроен плеер

- **Один `new Audio()`** на всё приложение: при смене трека меняется только `audio.src`,
  поэтому два трека никогда не играют одновременно. Тега `<audio>` в HTML нет.
- Состояние: `state = { category, trackId, isPlaying, volume, … }`.
- **Категории.** Клик фильтрует `tracks.json` по полю `category` и перерисовывает
  список. Играющий трек при этом не прерывается.
- **Список.** Клик по треку запускает его и подсвечивает строку, повторный клик ставит на
  паузу, ещё один продолжает воспроизведение. Играющая строка отмечена анимированным
  эквалайзером.
- **Prev / Next** переключают треки по кругу внутри категории *играющего* трека, даже если
  в списке сейчас открыта другая категория.
- **Прогресс.** Полоса обновляется по `timeupdate` (`currentTime / duration × 100%`),
  таймер показывает `1:24 / 3:45`. Клик по полосе перематывает трек
  (`audio.currentTime = доля × duration`), полосу можно и перетаскивать.
- **Громкость.** `input type="range"` 0–100 → `audio.volume = value / 100`. Mute глушит
  звук, повторный клик возвращает прежнюю громкость. Иконка меняется: обычная, тихая,
  перечёркнутая.
- **Автопереход.** По событию `ended` включается следующий трек.
- **Дополнительно:** режимы shuffle и повтора трека, «нравится», тёмная/светлая тема,
  пробел = play/pause, управление медиаклавишами (Media Session API), адаптивная вёрстка.
  Тема, громкость и лайки сохраняются в `localStorage`.

## Музыка

Все 21 трек — **оригинальные композиции, сочинённые и синтезированные кодом**
(`scripts/`). Скрипт сам пишет ноты: джазовые гармонии, walking bass, блюзовые квадраты
с ликами, классические периоды, канон. Затем он синтезирует звук (фортепиано, Rhodes,
вибрафон, контрабас, саксофон, труба с сурдиной, флейта, губная гармошка, орган Hammond,
струнные, арфа, клавесин, гитары методом Карплуса — Стронга, барабаны и дойра) и кодирует
результат в MP3. Сторонних сэмплов и чужих записей нет. Исполнители в `tracks.json`
вымышлены, названия джазовых треков взяты из макета.

Перегенерировать треки (нужен Python 3.10+):

```bash
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/generate_music.py              # все треки + tracks.json
.venv/bin/python scripts/generate_music.py blues/2      # один трек
```

### Как заменить музыку своими файлами

Положите mp3 в `public/music/<категория>/` (например `public/music/jazz/7.mp3`) и
добавьте или поправьте запись в `public/tracks.json`: `title`, `artist`, `category`,
`file` (путь от `index.html`, например `"public/music/jazz/7.mp3"`). Поле `duration`
можно не указывать.
